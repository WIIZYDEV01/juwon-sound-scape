# De Soundwave (juwon-sound-scape)

Music streaming app for browsing artists by country, searching songs, playing tracks, downloading offline, and viewing lyrics.

## Stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn-ui
- Supabase Auth

## Run locally

```sh
npm i
npm run dev
```

Open [http://127.0.0.1:8080/](http://127.0.0.1:8080/).

Copy `.env.example` to `.env` and fill in your keys (never commit `.env`).
